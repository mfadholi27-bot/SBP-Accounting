ARSIP PERMANEN
Perlindungan data

Tahap ini membuat salinan lengkap database ke folder server. Data aktif tidak dipindahkan atau dihapus. Rentang lima tahun menjadi label periode arsip; pemisahan data per tahun dan pembukaan arsip langsung akan dikembangkan pada tahap berikutnya.

Hubungkan folder server melalui menu Backup & Restore sebelum membuat arsip.

Arsip akan disimpan di folder ARSIP_5_TAHUNAN bersama file checksum SHA-256.

Jangan menghapus atau memindahkan database aktif berdasarkan arsip tahap awal ini. Setelah arsip dibuat, salin ke media kedua yang terpisah.

Backup & pemulihan data

Database utama tetap tersimpan di laptop. Hubungkan folder bersama server kantor untuk menyimpan salinan cadangan otomatis.

OFFLINE BACKUP

1. Hubungkan folder server

Pilih folder bersama (misalnya Z:\\SBP_ACCOUNTING atau folder jaringan kantor). Browser meminta izin tulis satu kali; izin mungkin perlu diaktifkan lagi setelah browser ditutup atau kebijakan kantor berubah.

2. Backup otomatis

Backup dibuat setelah perubahan data, setiap 30 menit saat aplikasi aktif, dan saat folder pertama kali dihubungkan. File terbaru dan arsip harian disimpan terpisah.

3. Pulihkan backup

Memuat kembali data dari backup JSON. Data lokal saat ini akan digantikan. Buat backup kondisi sekarang sebelum pemulihan.

Belum ada folder server yang dihubungkan. Pilih folder bersama terlebih dahulu.

Penting: backup otomatis hanya berjalan ketika aplikasi terbuka dan izin folder tersedia. Jika jaringan server terputus, data tetap tersimpan di laptop; backup akan dicoba lagi setelah koneksi pulih dan aplikasi aktif. Jangan jadikan folder backup sebagai satu-satunya salinan data.
