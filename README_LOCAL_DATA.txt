DATA LEGACY LOKAL
=================
File NPTRANS.DBF dan NPSALDO.DBF sengaja tidak disertakan dalam paket source ini
untuk mencegah data perusahaan terunggah ke GitHub atau dibagikan tanpa sengaja.

Jika aplikasi membutuhkan file legacy, salin file yang berwenang Anda gunakan ke
folder ini secara lokal. Jangan commit atau upload file DBF asli ke repository.
File sumber legacy harus diperlakukan sebagai read-only.
