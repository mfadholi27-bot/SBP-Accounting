Pembaruan preview GitHub Pages ke V4
1. Buka repository SBP-Accounting > index.html.
2. Klik ikon pensil (Edit this file).
3. Ganti seluruh isi index.html dengan isi index.html dari paket ini, lalu Commit changes.
4. Jangan unggah file ini sebagai file baru dengan nama berbeda; GitHub Pages memakai index.html di root.
5. Setelah commit, tunggu deployment lalu refresh paksa (Ctrl+F5).
Tema warna, neumorphism, ikon dan layout V3 dipertahankan; perubahan utamanya adalah label V4 dan keterangan status preview.
Ini hanya preview HTML, bukan backend akuntansi yang sudah terhubung.
