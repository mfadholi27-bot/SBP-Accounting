# SBP Accounting — UI Preview

Prototipe visual desktop-first bertema Neumorphism / Soft UI.

**Penting**
- Ini hanya prototipe antarmuka; belum terhubung ke SQLite, NPTRANS.DBF, atau NPSALDO.DBF.
- Aplikasi produksi tetap direncanakan sebagai Windows Desktop C# WinForms yang bekerja offline.
- GitHub Pages hanya untuk melihat prototipe. Jangan unggah database, DBF, backup, kata sandi, atau data sensitif perusahaan ke repository publik.
